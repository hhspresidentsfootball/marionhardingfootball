GITHUB UPLOAD:
1. Open your marionhardingfootball repository.
2. Click Add file > Upload files.
3. Drag index.html AND the entire assets folder into the upload area.
4. Commit directly to the main branch.
5. Go to Settings > Pages.
6. Choose Deploy from a branch.
7. Select main and /(root), then Save.

Do not rename any files or move files out of the assets folder.
